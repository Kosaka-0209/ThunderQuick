# ThunderQuick

## ゲーム内容

反射アクションと弾幕回避を組み合わせたゲームです。
プレイヤーはマウスドラッグで移動方向を決定し、壁での反射を利用しながら敵への攻撃を狙います。
ゲームは「計画フェーズ」と「回避フェーズ」に分かれており、攻撃経路を考える戦略性と、敵の攻撃を避けるアクション性を組み合わせました。

## 使用技術

- 言語：C++
- 主な技術：ベクトル計算、反射処理、当たり判定、ゲームの状態管理

## ゲームシステム

### 1. 計画フェーズ

- マウスドラッグで移動方向を指定
- 壁に当たると進行方向が反射
- 反射を利用して敵への攻撃経路を考える
- 反射回数や移動距離を利用した攻撃システム

### 2. 回避フェーズ

- 敵が弾幕攻撃を行う
- WASDキーでプレイヤーを操作
- 敵の攻撃を避けながら次の計画フェーズを目指す

## ソースコード


- Main.cpp: ゲームのメイン処理 
- Game.cpp: ゲーム進行・状態管理 
- Combat.cpp: 戦闘・攻撃処理
- Route.cpp: 移動経路・反射処理 
- PlayerVisual.cpp: プレイヤーの描画
- StageData.cpp: ステージデータの管理 
- Sound.cpp: サウンド関連処理 
- Config.hpp: ゲームの設定

## 制作で工夫したところ

特に工夫したのは、壁での反射を利用した移動経路の計算です。
プレイヤーが指定した方向へ単純に移動するのではなく、壁に衝突した際に進行方向を変化させることで、反射を利用したアクションを実現しました。
また、計画フェーズと回避フェーズではプレイヤーの操作方法やゲームの進行が異なるため、それぞれの状態に応じて処理を切り替える構成を意識しました。
さらに、戦闘、移動経路、描画、サウンド、ステージデータなどの処理をファイルごとに分割し、各機能の役割を明確にすることを心がけました。

## 制作で難しかったところ

特に難しかったのは、反射後の移動経路を正しく計算することです。
壁との衝突位置や進行方向を考慮する必要があり、複数回反射した場合でも意図した経路になるように調整しました。

## 制作を通して学んだこと

今回の制作を通して、ベクトルを利用した移動処理や反射計算など、ゲーム開発における数学的な知識の重要性を学びました。
また、ゲームの状態に応じて処理を切り替える方法や、機能ごとにファイルを分割して管理する設計についても理解を深めました。
